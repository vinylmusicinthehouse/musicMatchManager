# Overlap Explorer (GitHub Pages ready)

This folder is ready to publish on **GitHub Pages**.

## Quick publish steps
1. Create a new GitHub repo (e.g., `overlap-explorer`).
2. Upload the **contents of this folder** (make sure `index.html` is at the repo root).
3. In the repo: **Settings → Pages** → Source: **Deploy from a branch**. Select `main` and `/ (root)`. Save.
4. Wait ~1 minute. Your site will be live at the URL shown in the Pages section.

### Optional
- To use a custom domain, add a `CNAME` file with your domain name.
- To test locally: from this folder run `python3 -m http.server 8080` and open http://localhost:8080.
